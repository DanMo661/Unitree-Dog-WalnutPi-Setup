# Go2 Air SBUS 遥控桥 —— 新手完整指南

用一块百元级开发板读取云卓 G12 接收机的 SBUS 信号，通过 WebRTC（手机 App 同款通道）
控制宇树 Go2 Air（固件 1.1.11）的运动和模式切换，附带浏览器遥控页面。

```
G12遥控器 ──2.4G──► G12接收机 ──SBUS──► [反相] ──► 开发板
                                                    ├─ 解码SBUS、摇杆→速度、开关→模式
                                                    └─ WebRTC ──► Go2 (热点 或 网线)
```

> 重要背景：Go2 Air 上官方 SDK(DDS) 是不通的，只能走 App 的 WebRTC 通道；
> 固件 ≥1.1.7 换了新指令集(MCF)，本代码已按新指令集编写；1.1.1–1.1.14 免密钥可用。
> **请在 App 里关闭"固件自动升级"，锁住 1.1.x，否则随时可能再次失效。**

## 二、电脑上要装的软件（全免费）

1. **balenaEtcher**（balena.io）—— 把系统镜像烧进 TF 卡
2. **MobaXterm**（或 Windows Terminal + WinSCP）—— SSH 登录开发板 + 拷贝文件
3. Orange Pi 官网（orangepi.cn → 资料下载 → Zero 2W）下载 **Ubuntu/Debian Server 镜像**
4. Unitree App（手机上已有）—— 查固件版本、关闭自动升级

## 三、接线图

```
G12接收机                  开发板(Orange Pi Zero 2W)
┌─────────┐
│ VCC ────┼── 5V(板子5V脚) 或 升压模块12V   ← 按接收机型号定!
│ GND ────┼── GND(板子GND, 必须共地)
│ SBUS ───┼── [反相小板输入] ──输出──► USB-TTL的RX
└─────────┘                        USB-TTL插板子USB口
```

三极管方案（若自焊）：
```
                3.3V
                 │
               [10kΩ]上拉
                 │
SBUS ──[10kΩ]──B C────► 接USB-TTL的RX
               (NPN)
                 E
                 │
                GND(共地)
```

## 四、开发板系统安装（第一次约 30 分钟）

1. balenaEtcher 烧录 Orange Pi 镜像到 TF 卡 → 插卡、插网线(连家里路由器)、通电
2. 路由器后台找到开发板 IP → MobaXterm SSH 登录（账号/密码：orangepi / orangepi）
3. 连接狗的两种方式（二选一，写在 main.py 的 METHOD 里）：
   - **LocalAP（推荐起步）**：开发板连狗热点
     `nmcli dev wifi connect GO2-XXXXXX password "热点密码"`
     （热点密码 8 位，默认多为 00000000，App 里可查；此时狗在 192.168.12.13）
   - **LocalSTA（外场免线/低延迟）**：让狗连家里路由器（App 里配），开发板也连路由器，
     在路由器后台查狗的 IP 填进 ROBOT_IP；网线直连则狗固定为 192.168.123.18
4. 拷贝本目录所有文件到板子（如 /home/orangepi/go2rc/），执行 `bash install.sh`

## 五、分步测试（每一步通过再进行下一步！）

1. **SBUS 测试**：`python3 sbus_test.py`
   - 搬动摇杆看 16 个通道值变化（172~1811，中值约 992）
   - 记下：哪个通道是前后/侧移/转向/三段模式/解锁开关、各行程范围
   - 关掉遥控器 → 失控标志应变 1
2. **WebRTC 测试**（先不接狗运动）：跑库内交互示例
   `python3 -m unitree_webrtc_connect ...` 或按库 README 跑 examples/go2 的
   sportmode_mcf 示例，确认能连接、能用菜单发 Damp/StandUp/BalanceStand/Move/StopMove。
   **顺便记录 SwitchAvoidMode(2058) 和 SpeedLevel(1015) 的参数名**，
   回来填到 main.py 的 p_avoid/p_level，并把 ENABLE_AVOID 改 True（如需避障开关）。
3. **联调**：把 sbus_test.py 记下的通道号填进 main.py 配置区 → `python3 main.py`
   - 狗架空或空旷平地；先只测模式开关（趴/站/走）
   - 再动摇杆，初期限速 0.5 m/s
4. **失控测试**：运动中关遥控器 → 应立刻停住、2 秒后趴下。每次改程序后都要复测。
5. **断链测试（此路径特有）**：运动中杀掉板子程序/断开 WiFi，架空观察狗的行为，
   以此决定限速上限。
6. **网页端**：浏览器开 `http://开发板IP:8000`（RC 未解锁时网页才有效）。
7. **自启动**：
   ```
   sudo cp go2rc.service /etc/systemd/system/
   sudo nano /etc/systemd/system/go2rc.service   # 把路径改成实际目录
   sudo systemctl enable --now go2rc
   journalctl -u go2rc -f                        # 看日志
   ```

## 六、常见问题

| 现象 | 排查 |
|---|---|
| sbus_test 一直无帧 | 串口号不对 / TXRX接反 / 忘做反相 / 接收机没电 / 适配器不支持100000波特率 |
| 数值乱跳 | 反相没做对；共地没接 |
| WebRTC 连接超时 | 板子没连上狗网络；手机 App 占用连接（一次只允许一个客户端）；固件≥1.1.15 需先抓密钥 |
| 连上但指令被拒 | 未起立就发 Move；先 StandUp 再 BalanceStand（代码已处理延时） |
| Move 方向反了 | 把 main.py 里对应通道 axis() 取负 |
| 升级固件后失效 | 预期内。关闭自动升级，等库里更新适配 |

## 七、安全须知

- 全程**解锁开关默认断开**，解锁才响应运动；上锁=趴下。
- 初期限速 0.5 m/s，架空测试优先；远离楼梯、水域、人群。
- WebRTC 是逆向通道，没有官方失控保护：断链行为务必实测，速度别放开太快。
- 固件升级 = 此方案随时可能失效，**关闭自动升级**。
