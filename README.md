# Unitree-Dog-WalnutPi-Setup

**宇树 Go2 机器狗 × 核桃派 1B × G12 遥控器 —— 遥控链路配置流程**

从一张空 TF 卡到"遥控器直控机器狗"的完整配置 SOP 与全套部署源码。
三套实机全流程验证（dog1/2/3），SOP 以 dog3 为定稿基准。

## 这是什么

在宇树 Go2 机器狗体内装一块核桃派 1B（WalnutPi 1B），把云卓 G12 遥控器的 SBUS 信号
解码后经 WebRTC 发给狗主控，实现：物理遥控器直控（解锁/步态/摇杆/继电器）、
浏览器调试台、喊话/动作面板 App、失控保护。板子配 **WiFi 双档案**——主 WiFi（公司/家里，
静态 IP，高优先级）+ 手机热点（DHCP，低优先级兜底）——在任何场地都能无线调试，切换全自动。

## 快速开始

→ **[SOP.md](SOP.md) —— 完整配置流程（含每步技术坑）**

```
烧卡(15min) → 三条命令部署 → WiFi 双档案 → 狗自动连 → ★遥控器通道标定 → 验证清单
```

最重要的一条：**`config.py` 的遥控器通道标定是按特定一台 G12 实测的，每台新遥控器必须重新标定**（SOP §5，否则解锁/起立无反应）。

## 网络一览（详见 SOP §0）

```
狗主控 .161:9991 ←WebRTC─ 核桃派(.50/.10) ←SBUS─ GR01 ←2.4G─ G12 遥控器
                                     └ WiFi: 主WiFi(公司/家里,静态,高优先级) / 手机热点(DHCP,低优先级兜底)
```

## 已知边界（如实说）

- 狗固件锁 1.1.x（1.1.1~1.1.14 免密钥）；≥1.1.15 的狗需逐机取 AES key（`config.AES_KEY`）
- 核桃派 WiFi 芯片（unisoc UWE5622）偶发驱动级僵死，只能断电重启（SOP 坑 3.3）
- 每条狗内网独立，可复制部署；WiFi 侧 IP 必须每板不同（SOP §3）
