# 「蹲起」自定义动作 — 实现方案 v1（2026-10-14，待用户拍板）

目标动作：**站 → 蹲到一半 → 站起 → 蹲到一半 → 站起**，两次循环，全程平衡站姿，约 6~7 秒。

---

## 结论先行

**分两阶段做：先上路线 B（当天可用、零风险），并行探测路线 A（关节级正路）的通行证。**
两路线共用同一套"脚本动作"框架入口，以后所有自定义动作都长在这棵树上。

---

## 路线 B：BodyHeight(1012) 高层调身高 —— 第一阶段

**原理**：高层运动服务有独立的调身高指令（今天官方文档实证：站立时身高默认 0.33m，
可调范围 -0.18~+0.03m 相对值）。"蹲到一半" = 身高降到 0.33 + (-0.09) = 0.24m。
狗的平衡控制器自己稳住身体，我们只发高度目标，安全性由狗固件兜底。

**为什么 PRO 能用**：它与 Dance1/Hello/GetSpeedLevel 同属一个运动服务、走我们已跑通的
WebRTC 通道（心跳每 5 秒都在用这家服务，实证活着）。PRO 锁的是底层 LowCmd，高层不锁。

**参数**：api_id **1012**，参数 `{"data": <相对值>}`（单值指令键名模式与 SpeedLevel
一致，SDK 源码实证）。⚠️ 1012 不在 C++/Py SDK 常量表里（1010~1015 之间的空档），
需在 bridge 里手动补 `SPORT_CMD_MCF["BodyHeight"] = 1012`，首测先发 -0.03 小深度试探。

**时间线草案**（蹲起 v1）：

| t(秒) | 动作 | 说明 |
|-------|------|------|
| 0.0 | BalanceStand | 确保平衡站姿 |
| 0.3 | BodyHeight(-0.09) | 降到半蹲 |
| 1.1 | BodyHeight(0) | 起立（控制器内部平滑） |
| 1.9 | BodyHeight(-0.09) | 第二次蹲 |
| 2.7 | BodyHeight(0) | 起立 |
| 3.3 | BalanceStand | 收尾 |

动作锁（冷却）6s；深度/节奏实机校准。

**交付物**：
1. bridge.py 新增「脚本动作」框架：`SCRIPTS = {"蹲起": [(t, 指令, 参数), ...]}`，
   专用线程按时间线发指令，复用现有动作锁/横幅"动作播放中"/配乐/TRICK 白名单机制
   ——这就是以后所有自定义动作的地基（编排级也长在这上面）
2. App v36：动作面板加「蹲起」按钮（构建上架流程现成）
3. 仿真测试 + 实机深度校准（-0.03/-0.06/-0.09 三档试）

**风险**：低。最坏情况=固件不认 1012（回包拒绝/狗不动），退回路线 A，无副作用。

## 路线 A：SDK2 关节级 LowCmd —— 第二阶段（你点名的正路）

**第一步行前探针（免费）**：板子修好 WiFi 后装 cyclonedds+sdk2py（**板装依赖属红线，
做之前要你点头**），只跑 `CheckMode→ReleaseMode` 看咱这条 1.1.1~1.1.14 老固件的 PRO
放不放行底层。放行→继续；被锁→停在路线 B，越狱另立项评估。

**squat_worker.py 设计**（放行后开发）：
1. 接管流程：CheckMode 循环 → StandDown + ReleaseMode（遥控期间失效几秒，正常）
2. 500Hz LowCmd 位置式控制（kp=60/kd=5），关节目标：
   - 站姿 [0, 1.36, -2.65]×4 腿（官方示例实证）
   - 蹲姿 [0, 0.67, -1.3]×4 → **半蹲 = 两表 50% 插值 ≈ [0, 1.0, -2.0]×4**
   - 序列：从实测起始角缓动到站姿 → 半蹲 → 站 → 半蹲 → 站
3. 退出兜底（finally + systemd OnFailure 双保险）：`SelectMode("ai")` 恢复运动服务 +
   上层补 StandUp，绝不让狗留在"无主"状态
4. 入口融合：动作面板「蹲起Pro」按钮，同一脚本框架触发，桥经本地 UDP/子进程调 worker

**额外自由度（值得上 A 的原因）**：关节级可以做出"颤膝""重心左右压腿""单腿点地"这类
身高指令做不出的细节，以后编舞用。

**风险**：PRO 被锁（探针免费验）；ReleaseMode 窗口期遥控全废（几秒，自动恢复）；
控制参数不当会摔（kp/kd 减半起步、首测架高）。

---

## 安全设计（两路线通用）

- 触发前置：站立(mode=2) + 链路 up + 无动作占用（复用现有 trick 门，趴着/走着按了不发）
- 过程中：脚本持有动作锁，遥杆输入被现有 cooldown 机制忽略；**C 拨下 = 立即终止脚本**
  （脚本线程监视 stand 电平，中断即走恢复路径）
- 收尾/异常：finally 必发归零（路线 B：BodyHeight(0)+BalanceStand；路线 A：SelectMode）
- 首测：空旷平地，深度从 -0.03 起，人在旁边
