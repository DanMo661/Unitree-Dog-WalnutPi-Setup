# ADR-0006: 测试零第三方依赖，run_test_shim 统一入口

- 状态: 采纳
- 日期: 2026-10-31
- 关联: run_test_shim.py、全部 test_*.py（撰写时 16 套，只增不减）、tools/check_deps.py（依赖方向守门，同日落地 6aa0a23）

## 背景

测试需要跑在三种环境：板上 venv、PC 多版本 Python（3.13+ 已移除 audioop）、子代理沙箱。
曾讨论 pytest 化，被否。

## 决策

- 所有 `test_*.py` 只用 stdlib，自写 `ok()` / `FAILS` 断言，退出码非零即失败。
- `run_test_shim.py` 为无 audioop 的解释器提供垫片入口：`python run_test_shim.py test_xxx.py`。
- 板端集成测试（如 `test_pa_v3.py` 需真机在线）缺省 `BRIDGE_HOST=127.0.0.1` 防误发真网，
  文件头明确标注"离线跑必然 FAIL"。

## 理由

- 零依赖 = 任何裸环境开箱即跑：板子 pip 装东西受网络限制，PC 多环境有版本漂移，
  子代理沙箱不可预测；测试自身不能成为"要先修环境才能验证"的东西。
- pytest 化的收益（fixture/参数化/插件）对本项目 16 套小而独立的脚本没有实质收益，
  反而引入安装耦合和一套要学的新断言语义。

## 权衡

没有参数化、没有断言重试，样板代码略多；可读性换来可移植性，接受。

## 后果

- 新测试**禁止 import 任何第三方包**；tools/check_deps.py 守这条线。
- 新测试文件名必须 `test_*.py` 放仓库根，与现有 16 套并列，不建 tests/ 目录（部署清单按根通配收集）。
