# ADR 使用说明

ADR（Architecture Decision Record）记录**代码本身看不出来的决策**：
为什么这样设计、当时放弃了什么、什么条件下这个决策作废。
新协作者（人或 agent）改安全 / 协议 / 并发语义前，先查这里有没有对应决策；
做出新的不可逆取舍时，照模板新增一条，编号递增，已发布的不改写（推翻就新增一条标"被 XXXX 取代"）。

---

# ADR-NNNN: <一句话标题>

- 状态: 提议 | 采纳 | 已废弃（被 ADR-XXXX 取代）
- 日期: YYYY-MM-DD
- 关联: <commit 哈希 / 相关 ADR / 测试文件>

## 背景

当时面临什么问题，有哪些约束和压力（2-5 句）。

## 决策

选了什么，一段话说清，能落成规则就落成规则。

## 理由

为什么选它，关键事实和推演。

## 权衡

放弃了什么；什么情况下这个决策会失效；实现时必须小心的边界（如复合操作）。

## 后果

后来者必须知道什么；违反它会发生什么；由哪些测试锁定。
